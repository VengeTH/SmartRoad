# SmartRoad — Ride-Hailing Partner Agreement

> **Last updated:** 2026-06-09  
> **A product of The Heedful**

---

## 1. Purpose

This agreement governs partnerships between SmartRoad and ride-hailing platforms (Grab, Angkas, JoyRide, Move It, etc.) for enhanced routing and delivery intelligence.

## 2. Partner Benefits

| Feature | Description |
|---------|-------------|
| Gate-Aware Routing | Direct drivers to correct entrances |
| Scam Pin Intelligence | Avoid misleading drop-off locations |
| HOA Access Data | Know which villages require stickers |
| Weather-Aware Routing | Avoid flood-prone areas |
| Delivery Entrance DB | Correct drop-off points for deliveries |

## 3. Integration Options

- **API Integration**: Real-time routing data via SmartRoad API
- **SDK Integration**: Embed SmartRoad intelligence in partner apps
- **Data Feed**: Batch route intelligence data updates

## 4. Data Sharing

SmartRoad provides:
- Entrance location data (anonymized)
- Access rule information (public routes only)
- Hazard data along partner routes

Partner provides:
- Aggregated routing performance data
- Scam pin reports from their drivers

## 5. Revenue Model

| Model | Description |
|-------|-------------|
| Per-request API fee | ₱0.50 per routing request |
| Monthly subscription | ₱50,000/month for unlimited API access |
| Revenue share | 1% of delivery fees using SmartRoad routing |
